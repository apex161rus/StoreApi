### **Рефакторинг базы данных**

Иногда при разработке приложения возникает необходимость удалить все таблицы из базы данных, например, для полной очистки или подготовки к новой миграции. Ниже приведен SQL-скрипт, который поможет вам удалить все таблицы из базы данных PostgreSQL:
```
DO $$ DECLARE
    r RECORD;
BEGIN
    FOR r IN (SELECT tablename FROM pg_tables WHERE schemaname = 'public') LOOP
        EXECUTE 'DROP TABLE IF EXISTS ' || quote_ident(r.tablename) || ' CASCADE';
    END LOOP;
END $$;
```
                  
### **Этот скрипт удаляет все таблицы в схеме public вашей базы данных, используя цикл для перебора всех таблиц и команду DROP TABLE с опцией CASCADE, чтобы также удалить все зависимости.**
___
Этот скрипт может быть полезен для быстрого удаления всех таблиц перед началом новой фазы разработки или тестирования.
