## Подготовка базы данных с использованием Docker и pgAdmin

В этом руководстве мы рассмотрим, как создать контейнер с базой данных PostgreSQL с использованием Docker и управлять им через pgAdmin.

Демонстрация на следующем шаге

## Шаг 1: Установка Docker

Для начала скачайте и установите Docker, следуя инструкциям на официальном сайте Docker. Docker позволяет запускать приложения в изолированных контейнерах, что упрощает управление и развертывание приложений.

## Шаг 2: Проверка установки Docker

После установки Docker, проверьте его версию, чтобы убедиться, что он установлен правильно. В терминале выполните команду:
```
docker --version
```
                  
Если Docker установлен, вы увидите сообщение с номером версии, например:
```
Docker version 27.1.1, build 6312585
```
                  
### Если Docker не установлен, вы получите сообщение об ошибке:

**Windows** 
```
C:\test> docker -- version
```
**Имя "docker" не распознано как имя командлета, функции,
файла сценария или выполняемой программы.
Проверьте правильность написания и повторите попытку.**

                  
 Mac OS

docker: command not found

                  
## Шаг 3: Установка pgAdmin

Скачайте и установите pgAdmin с официального сайта pgAdmin. Это инструмент для управления базами данных PostgreSQL, который предоставляет удобный графический интерфейс для администрирования.

## Шаг 4: Создание контейнера с PostgreSQL

Теперь создадим контейнер с PostgreSQL. Убедитесь, что Docker установлен и запущен. Затем выполните следующую команду в терминале:
```
docker run --name store-api -e POSTGRES_PASSWORD=12345678 -p 5432:5432 -d postgres
```
                  
Эта команда создаст и запустит контейнер с именем store-api, установит пароль для пользователя postgres и откроет порт 5432 для подключения к базе данных.

## Шаг 5: Подключение к базе данных через pgAdmin

После установки pgAdmin откройте его и добавьте новое подключение к базе данных:

В поле Host укажите localhost или 127.0.0.1
В поле Port укажите 5432.
В поле Username укажите postgres.
В поле Password укажите 12345678.
После заполнения всех полей нажмите Save, чтобы сохранить подключение. Теперь вы можете управлять вашей базой данных через pgAdmin.

Заключение

Вы успешно создали контейнер с базой данных PostgreSQL с использованием Docker и подключились к нему через pgAdmin. Этот подход обеспечивает изоляцию и простоту управления базой данных
