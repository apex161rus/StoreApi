# 📦 Подключение зависимостей для проекта .NET API

Вы можете воспользоваться подготовленным шаблоном проекта
```
https://github.com/iksergey/store-api-public/tree/dev-dotnet-9
```
```
git clone https://github.com/iksergey/store-api-public.git
git checkout dev-dotnet-9
```

В рамках этого шага были установлены необходимые зависимости

## Шаги выполнения

### Шаг 1: Проверка текущей директории
Убедитесь, что терминал находится в папке Api. Выполните команду:
pwd
Проверьте, что путь заканчивается на /Api.

### Шаг 2: Подключение библиотек
Находясь в правильной директории, выполните следующие команды для подключения необходимых пакетов:

**Для аутентификации с использованием JWT:**
```
dotnet add package Microsoft.AspNetCore.Authentication.JwtBearer --version 9.0.3
```
___

**Для использования Identity с Entity Framework Core:**
```
dotnet add package Microsoft.AspNetCore.Identity.EntityFrameworkCore --version 9.0.3
```
___
**Для инструментов разработки Entity Framework Core:**
```
dotnet add package Microsoft.EntityFrameworkCore.Tools --version 9.0.3
```
___
**Для дизайна Entity Framework Core:**
```
dotnet add package Microsoft.EntityFrameworkCore.Design --version 9.0.3
```
___
**Для работы с PostgreSQL через Entity Framework Core:**
```
dotnet add package Npgsql.EntityFrameworkCore.PostgreSQL --version 9.0.4
```
___
**Для поддержки OpenAPI (Swagger):**
```
dotnet add package Microsoft.AspNetCore.OpenApi --version 9.0.3
```
___
**Если вы используете .NET9 может потребоваться зависимость Swashbuckle.AspNetCore для нормальной работы Swagger так как Microsoft убрали её из стандартного пакета.**
```
dotnet add package Swashbuckle.AspNetCore --version 8.0.0
```
Или если у вас уже установлен, обновите до последней версии:

```bash
dotnet add package Swashbuckle.AspNetCore
```

После этого выполните:

```bash
dotnet restore
```
___
**Для генерации фейковых данных: прежде чем выполнять команду, перейдите на страницу зависимости и выберите последнюю версию для .net 9. На декабрь 2024 это 35.6.1**
```
dotnet add package Bogus --version 35.6.2
```
___                  
**Если вы используете .NET9 может потребоваться зависимость Swashbuckle.AspNetCore для нормальной работы Swagger так как Microsoft убрали её из стандартного пакета.**
```
dotnet add package Swashbuckle.AspNetCore --version 8.0.0
```
___
Эти команды добавят необходимые библиотеки в проект, что позволит использовать их функциональность в приложении.
