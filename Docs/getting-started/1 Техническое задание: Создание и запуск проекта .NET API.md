# Техническое задание: Создание и запуск проекта .NET API

## Цель
Создать и запустить простой проект API с использованием .NET, следуя пошаговым инструкциям.

---

## Шаги выполнения

### 1. Создание решения
**Описание:** Создать новое решение для хранения проекта API.  
**Команда:** `dotnet new sln -n StoreApi`  
**Результат:** Создан файл решения StoreApi.sln.

### 2. Создание проекта Web API
**Описание:** Создать новый проект Web API внутри созданного решения.  
**Команда:** `dotnet new webapi -n Api`  
**Результат:** Создан проект API с именем Api в новой папке.

### 3. Добавление проекта в решение
**Описание:** Добавить проект API в файл решения.  
**Команда:** `dotnet sln add ./Api/Api.csproj`  
**Результат:** Проект Api добавлен в решение StoreApi.sln.

### 4. Создание файла .gitignore
**Описание:** Создать файл .gitignore для исключения ненужных файлов из системы контроля версий.  
**Команда:** `dotnet new gitignore`  
**Результат:** Создан файл .gitignore для исключения временных файлов и артефактов сборки.

### 5. Переход в директорию проекта
**Описание:** Перейти в директорию проекта API для его запуска.  
**Команда:** `cd Api`

### 6. Запуск проекта с наблюдением за изменениями
**Описание:** Запустить проект с автоматическим отслеживанием изменений в коде без перезагрузки.  
**Команда:** `dotnet watch --no-hot-reload`  
**Результат:** Сервер запущен и следит за изменениями в коде, автоматически пересобирая проект при необходимости.

---

## Ожидаемый результат
После выполнения всех шагов проект API будет готов к использованию и дальнейшей разработке.

---

## Все команды для копирования
```bash
dotnet new sln -n StoreApi
dotnet new webapi -n Api
dotnet sln add ./Api/Api.csproj
dotnet new gitignore
cd Api
dotnet watch --no-hot-reload
```
