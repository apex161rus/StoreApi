## Миграции
Демонстрация на следующем шаге, сейчас проделывать ничего не нужно. Сперва посмотрите ролик

В этом разделе мы рассмотрим, как настроить ваше приложение .NET для работы с базой данных, используя миграции Entity Framework Core.
___

### Шаг 1: Переход в директорию проекта

Прежде чем начать, убедитесь, что ваш терминал находится в директории проекта Api. Это необходимо для правильного выполнения команд миграции. Выполните команду:
```
cd Api
```
___                  
### Шаг 2: Добавление миграции

Миграции позволяют управлять изменениями в структуре базы данных. Чтобы добавить миграцию, выполните следующую команду:
```
dotnet ef migrations add Add-Db-Context
```
                  
Эта команда создаст файлы миграции, которые содержат инструкции для создания и изменения таблиц в базе данных.

Если при выполнении этой команды вы получаете ошибку, похожую на


**> Не удалось выполнить, поскольку указанная команда или файл не найдены.**
**Возможные причины этого включают:**
* Вы допустили ошибку во встроенной команде dotnet.**
* Вы собирались выполнить программу «NET, но dotnet-ef не существует.
* Вы собирались запустить глобальное средство, но в РАТН не удалось найти исполняемый файл с префиксом

                  
Проверьте установлены ли у вас инструмент dotnet-ef 
```
dotnet ef --version
```
Если нет - установите его командой 
```
dotnet tool install --global dotnet-ef
```
___
### Шаг 3: Обновление базы данных

После добавления миграции необходимо обновить базу данных, чтобы применить изменения. Выполните команду:
```
dotnet ef database update
```
                  
**Эта команда применит все миграции к базе данных, создавая или изменяя таблицы в соответствии с вашей моделью данных.**
