## Интеграция базы данных в проект .NET

#### В этом разделе мы рассмотрим, как интегрировать базу данных PostgreSQL в ваш проект .NET, используя строку подключения.

Демонстрация на следующем шаге

**Шаг 1: Добавление строки подключения**

Для начала откройте файл appsettings.Development.json в вашем проекте Api. Этот файл используется для хранения конфигурационных данных приложения.

Добавьте следующую строку подключения в секцию  
#### ConnectionStrings:

```
{
  "ConnectionStrings": {
    "PostgreSQLConnection": "Host=localhost;Port=5432;Username=postgres;Password=12345678;Database=store-api"
  }
}
```
                  
Эта строка подключения содержит информацию о хосте, порте, имени пользователя, пароле и имени базы данных, которую мы будем использовать.

#### Общий вид, примерно такой:

```
{
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft.AspNetCore": "Warning"
    }
  },
  "ConnectionStrings": {
    "PostgreSQLConnection": "Host=77.73.132.184;Port=6540;Username=postgres;Password=Gtfa1928hh1J45bdc;Database=store-db-api"
  }
}
```
                  
 

**Теперь ваш проект подготовлен для работы с базой данных PostgreSQL интегрирована в проект .NET. Вы можете использовать Entity Framework Core для взаимодействия с базой данных, выполняя запросы и изменяя данные.**
